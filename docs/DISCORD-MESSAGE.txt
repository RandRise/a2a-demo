Hey team! Here's our final A2A demo and PowerPoint presentation. The ZIP contains everything we need to rehearse. My API key is NOT included, and you don't need a key for Rehearsal mode.

SETUP
1. Extract the whole ZIP first, then open the a2a-demo folder.
2. Install Node.js if needed (version 20.18 or newer).
3. Open a terminal in that folder and run:
   npm ci
   npm start
4. Open http://127.0.0.1:8780 and keep the terminal running.

TRY THIS FIRST — NO KEY NEEDED
Choose Rehearsal and "Discuss the trade-off", then start the handoff. Answer "Separate breakout rooms" when the specialist asks. Watch the recommendation and coordinator review. Open Protocol inspector to see the actual A2A requests and task ID. Then start a new run with "Prioritize a quiet room" and compare the result.

Rehearsal uses scripted decisions with real local A2A HTTP. Live AI is optional: use your OWN OpenAI key in a local .env copied from .env.example, restart the app, and select Live AI. This uses your API billing. Never share or commit .env.

PRESENTATION & GUIDE
Open presentation/Relay-Team-3.pptx in PowerPoint. It has 16 slides and speaker notes. For the interactive explanation, open a second terminal in a2a-demo, run npm run docs:dev, and visit http://127.0.0.1:5173.

Read START-HERE.md if you get stuck. If a port is already in use, stop your earlier demo terminal with Ctrl+C before starting again.
